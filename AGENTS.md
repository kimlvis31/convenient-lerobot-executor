# Agent setup guide for convLexecutor

- Use this checkout as the working directory. It contains the executor, scripts, datasets, external adapters, and outputs. Reuse LeRobot from an installed Conda environment. Confirm the actual folders before modifying an existing installation.
- Read the English `README.md` or `README.ko.md` for the setup sequence. The verified native version is LeRobot 0.6.2, revision `145cc7ea53e5864bd5efec4e9bb70ee799e47bd8`, with LIBERO. Read the model-environment requirements in the README and check for bfloat16 support before preparing examples.
- Check the existing Conda environments first. Reuse `lerobot` and either `tinyvla_infer` or `lerobot_tinyvla` when compatible. Install the TinyVLA evaluation adapter only in the native LeRobot environment.
- Run `python -B scripts/prepare_examples.py --dry-run` before calling the same command without `--dry-run`. Preparation verifies or downloads the pinned public base weights and the selected demonstration files, then generates the two local example fixtures if needed. Existing files are checked before reuse. Preserve user-created datasets and checkpoints.
- Check installation with `python -B executor/manage.py --inventory`. Preview the example queue with `python -B executor/manage.py --queue scripts/example_script.py --dry-run`. For an actual smoke test, run the queue and check `status.json`, `run.py`, `script.py`, and the stage outputs. Distinguish a completed evaluation from task success.
- Keep fetched data, weights, experiment outputs and logs out of Git. Sources and attribution are in `THIRD_PARTY.md`. First-party executable scripts are AI-written and the README records that provenance.
