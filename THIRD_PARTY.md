The VLABench recipe imports the pinned path-planner source directly and uses Rtree 1.4.1. The upstream 1.2.0 Linux wheel has malformed platform-tag headers that fail current package validation. The manager keeps upstream source metadata unchanged and verifies the planner's real obstacle/collision queries with the compatible 1.x runtime.

Automatic source-benchmark preparation follows the corresponding [LeRobot benchmark recipes](https://github.com/huggingface/lerobot/tree/145cc7ea53e5864bd5efec4e9bb70ee799e47bd8/docker). Those reference files carry Apache-2.0 notices. The first-party setup and process-bridge scripts were written by AI and are distributed under this repository's license. Downloading third-party sources, model weights, or simulator assets does not relicense them under this project's MIT license. Fetched archives, build products, source checkouts, and installed runtime environments are excluded from Git.
